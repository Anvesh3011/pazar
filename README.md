# Pazar

A multi-category e-commerce and inventory intelligence platform.

Pazar is a full-stack web application where customers can discover
and purchase products across multiple categories, while administrators
manage products, inventory, orders, customers, and business analytics.

## Project Goals

- Build a responsive customer-facing storefront.
- Develop a secure, data-driven admin dashboard.
- Implement reliable order processing and inventory management.
- Learn relational database design and advanced SQL.
- Apply professional testing, version control, and deployment practices.

## Planned Technology Stack

- Frontend: React and TypeScript
- Backend: Node.js, Express, and TypeScript
- Database: PostgreSQL
- Database migrations: node-pg-migrate
- Version control: Git and GitHub
- Testing and deployment: To be configured during development

## Initial Scope

- Single-vendor, multi-category store
- Customer and administrator roles
- Product catalog and shopping cart
- Demonstration checkout without real payments
- Order and inventory management
- Sales and inventory analytics

## Development Status

Project setup and database design.

Features are planned and will be implemented incrementally.

## Development Principles

- Validate input and authorization on the server.
- Enforce data integrity through database constraints.
- Use transactions for critical business operations.
- Write tests for important business rules.
- Keep secrets out of source control.
- Document meaningful design decisions.
